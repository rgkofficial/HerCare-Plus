🌟 Project Vision & Architectural Mandate
HerCare Plus is Tech Tomorrow's flagship production-grade women's healthcare platform. Your core responsibility is to engineer a world-class, high-performance Conversational Healthcare Chat UI Studio that feels as fluid and responsive as ChatGPT, Perplexity, and v0, tailored specifically for clinical symptom intake, cycle health guidance, and telehealth assistance.

🎯 Exhaustive Engineering Scope & Deliverables
1. Premium Conversational Chat Interface (UI/UX)
Fluid Message Feed: Auto-scrolling, bi-directional message rendering (User vs AI Assistant) with smooth fade-in and typewriter/streaming pulse animations.
Rich Markdown & Content Rendering: Support for structured medical explanations with clean headings, bulleted symptom lists, medical reference tables, code snippets, and highlighted warning blocks.
Interactive Quick-Prompt Chips: Contextual suggested prompts at the top of the chat (e.g., "Log period symptoms", "Explain PCOS risk factors", "Prepare questions for Gynecologist", "Understand iron deficiency anemia").
Mobile-First Responsive Layout: Full-height viewport adaptation (dvh/vh units), sliding drawer menu for mobile navigation, and floating action buttons.
Modern Theme Aesthetics: Sleek modern palette (slate/emerald/rose accents), subtle backdrop blurs (glassmorphism), and dark/light mode toggle support.
2. Session Management & History Architecture
Multi-Session Drawer: Sidebar showcasing active and past chat threads grouped by date (Today, Yesterday, Last 7 Days).
Session Operations: Ability to start a new chat, rename conversations, search previous threads, and clear history.
Client Persistence & Cache: Instant UI hydration with local storage caching synchronized with backend session APIs.
3. Clinical Safeguards & Triage Warning Engine
Urgent Triage Detection: Visual severity alert cards (amber for moderate advisory, crimson red for emergency symptoms like acute severe abdominal pain or heavy bleeding).
Emergency Action Bar: Direct quick-call buttons for local emergency numbers and maternal health helplines when critical keywords are detected.
Source Citation & Grounding: Clear visual badges for verified healthcare knowledge sources (e.g., "Verified Clinical Guideline • WHO / ACOG").
Prominent Medical Disclaimer: Subtle, permanently visible legal footer stating: "HerCare Assistant provides educational health guidance and is not a substitute for professional medical diagnosis."
4. Frontend-Backend Streaming Integration
Streaming Pipeline: Implement handling for Server-Sent Events (SSE) or chunked HTTP stream reader for instantaneous character-by-character response rendering.
Resilience & Fallbacks: Graceful connection retry mechanisms, friendly offline indicators, and input rate-limiting safeguards.
