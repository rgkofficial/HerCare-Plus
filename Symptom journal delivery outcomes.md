# Symptom journal delivery outcomes

## Local-first symptom and pain journal

- [x] Menstrual cycle logging, an interactive date calendar, and configurable cycle predictions are available.
- [x] Period history and multi-symptom logging include flow intensity, cervical fluid, cramps, body temperature, mood tags, and pain severity.
- [x] PCOS and hormonal symptom tags support a clinician-discussion summary.

## Longitudinal trends and exports

- [x] Personalized trends include symptom-frequency correlations and Donut/Bar/Biphasic visual summaries.
- [x] CSV export and privacy-preserving PDF/print export are available.
- [x] Fertility-window estimates display transparent uncertainty badges and medical safety disclaimers.

## Reliability and privacy

- [x] Edge cases cover irregular cycles, missing days, leap years, and international timezone boundaries.
- [x] Sensitive journal data stays local by default; opt-in sync is authenticated and owner-scoped with negative authorization tests.
- [x] Working feature, automated results, API documentation, screenshots/demo path, and known limitations are documented.
